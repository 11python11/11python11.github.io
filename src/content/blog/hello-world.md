## 为什么是现在

这个念头其实出现过很多次：搭一个自己的博客。

每次都被同一个理由劝退——「等我把这个项目做完」「等我想清楚要写什么」「等模板再好看一点」。结果是项目一个接一个，想法也一个接一个地散掉，什么都没有留下来。

所以这次不等了。先把空本子打开，再慢慢往里写。

## 这里会有什么

不打算给这个博客设一个很窄的定位。大致会有三类内容：

- **技术笔记**：踩过的坑、读完的源码、折腾成功的配置。重点是记录「为什么」，而不只是贴代码。
- **项目复盘**：机器人竞赛、CTF、模型训练这类做完就忘的事情，趁还记得写下来。
- **随便想想**：一些还没有结论的观察。写不清楚也没关系，先放着。

> 写作不是把已经想好的东西打印出来，而是借助文字，把模糊的感觉逼成一个明确的句子。

## 为什么是静态博客

我不想为「写文章」这件事维护一台服务器。静态生成 + GitHub Pages 的组合足够便宜，也足够稳定：

- 文章是 Markdown 文件，存在 Git 仓库里，天然有版本历史
- 构建产物是纯 HTML/CSS/JS，不需要数据库和运行时
- 托管在 GitHub Pages 上，月度成本是 0 元

代价是评论、搜索这类功能不能靠后端实现。但博客刚起步，这些都可以往后放。

## 先写，再改

第一版一定不完美：排版会改，导航会改，甚至这个域名以后也可能换。但内容一旦写下来，就比留在脑子里强。

所以，就从这篇开始。
